# screenshots

Electron 跨屏截图工具：框选截图 → 直接在图上标注 → 钉住置顶 / OCR / 滚动长图。

## 功能

- **跨显示器截屏**：选区可以拖过屏幕边界，导出为一张拼接图。支持缩放比例不同的多块屏、负坐标虚拟屏
- **窗口捕获**：框选前光标悬停在应用窗口上时自动高亮该窗口（蓝框），**原地点击 = 整窗作为选区**，**按住拖动 = 照常画自定义选区**；`Tab` 在重叠窗口间轮换；按 z 序取最上层，自动过滤自身
- **选区碰撞**：选区拖动 / 调整时贴住虚拟桌面边界，不会越出屏幕（跨屏移动不受影响）
- **放大镜**：框选前跟随光标显示 4× 放大图与虚拟屏坐标；`Shift` 切换 `HEX` / `RGB`，`C` 复制当前颜色值；已有选区时光标在选区内仍可取色
- **标注**：箭头（实心/空心、头粗尾细）/ **直线** / 矩形 / 椭圆 / 画笔 / **荧光笔**（半透明加粗）/ 马赛克（选区 · 涂抹 · **高斯模糊**）/ **序号气泡**（点击自动递增）/ 文字（16–48 字号，**点选可二次编辑**），配色、线宽、撤销/重做/清空；已画标注可点选 → 移动 / 拖手柄 / 改色 / 删除
- **松手即可标注**：选区确定同时浮现工具条（图标化，两行式，行 2 为当前工具属性），无「确定」步骤——复制/保存就地合成，钉住进贴图
- **贴图**：无边框置顶贴图（透明窗口 + 外阴影）；**滚轮缩放**（光标处不动）、**Ctrl+滚轮 调透明度**、**双击复制**、**Ctrl+T 点击穿透**（托盘可恢复）、**✎ 二次标注**（完整标注工具条，导出含新标注）
- **滚动截长图**：工具条「长图」，区域与单屏取交集；**手动**滚轮 / **自动**注入滚轮（速度可切、移出选区即暂停、到底自动停）；行签名探针拼接，窗口框架不影响；完成后可复制 / 保存 / **转贴图二次编辑**
- **OCR 提取文字**：工具条「提取文字」，Windows 内置 WinRT OCR 离线识别，结果面板可一键复制（会话不中断，可继续标注）
- **截图历史**：复制 / 保存自动收录最近 20 张，托盘「截图历史」查看，缩略图列表支持复制 / 贴图 / 保存 / 删除
- **设置页**：主窗口内配置全局快捷键（捕获式录入，冲突自动回退）、开机自启、保存目录、默认格式（PNG/JPG，保存成功自动复制文件路径）
- 单块屏也能用：单击 = 选中整屏；支持延迟截图（托盘 5 秒）

## 使用

| 操作 | 方式 |
| --- | --- |
| 触发截图 | `Ctrl+Shift+A`（可在设置页修改）/ 主窗口按钮 / 托盘左键；托盘「5 秒后截图」 |
| 框选 | 按住左键拖动（可跨屏，桌面边缘碰撞贴边），松手出 8 向手柄 + 工具条；单击 = 整屏；`Enter`/双击/`Ctrl+C` = 复制，`Esc`/右键 = 取消 |
| 窗口捕获 | 框选前悬停窗口 → 蓝框高亮，原地点击 = 整窗选区，按住拖动 = 自定义框选；`Tab` 轮换重叠窗口 |
| 工具条 | 行 1 = 工具、撤销/重做/清空、`提取文字` `复制` `保存` `长图` `取消` `钉住`；行 2 = 当前工具属性（下拉/滑杆交互） |
| 标注 | 点选已画标注 → 移动/拖控制点/改色/`Delete` 删除；文字点选可二次编辑；序号点击自动递增 |
| 放大镜 | 框选前与选区内跟随光标（4× + 坐标 + 取色）；`Shift` 切 HEX/RGB，`C` 复制；选区外/重新框选时隐藏 |
| OCR | 工具条「提取文字」→ 结果面板（右上角）→ 一键复制；识别期间可继续标注 |
| 滚动长图 | 「长图」按钮（选区在单屏内）→ 遮罩收起 → 手动滚轮 / 自动注入（速度按钮切换，移出选区暂停，到底自动停）→ `编辑` `复制` `保存`；`Esc` 取消 |
| 贴图 | 钉住生成置顶贴图；滚轮缩放（光标处不动）、`Ctrl+滚轮` 透明度、双击复制、`Ctrl+T` 穿透（托盘恢复）、`✎` 二次标注、`Esc` 关闭 |
| 快捷键 | 选区阶段：`Ctrl+S` 保存、`Ctrl+Z`/`Ctrl+Shift+Z` 撤销重做、`Delete` 删标注、**方向键微调（1px，长按加速）**、`Esc` 取消——左下面板常驻提示 |
| 历史 | 托盘「截图历史」→ 缩略图列表 → 复制 / 贴图 / 保存 / 删除 |
| 退出 | 托盘右键 → 退出（关主窗口只是隐藏） |

## 快速开始

```bash
npm install
# npm 的 install-scripts 白名单会拦下 get-windows 的安装脚本（下载 N-API
# 预编译二进制），需要批准并补跑一次；koffi 同理（其预编译走 npm 本体）。
# 下载走 GitHub Releases，网络受限时先挂代理（如 HTTPS_PROXY=http://127.0.0.1:7890）
npm install-scripts approve get-windows
npm rebuild get-windows
npm start
```

```bash
npm run typecheck   # 类型检查
npm run lint        # ESLint
npm run package     # 打包成免安装目录
npm run make        # 生成安装包（Windows 走 Squirrel）
```

## 环境

- Node 22+、Electron 44，主要在 Windows 10/11 上开发（其他平台未验证）
- 依赖有上限，升级会与 Forge 插件的 peer 约束冲突：`typescript@5.x`、`eslint@8`、`vite@5`、`@electron/fuses@1`
- `.npmrc` 已把 Electron 二进制指向国内镜像（npmmirror）；`get-windows` 的预编译二进制在 GitHub Releases，受限网络用代理（见快速开始）
- OCR 使用 Windows 内置 WinRT OCR（跟随系统语言，无需联网）；自动滚动经 koffi 注入 `SendInput`
- Forge 的 rebuild 配置为**不重建任何模块**（`rebuildConfig.onlyModules: []`）：原生依赖 get-windows / koffi 均为 N-API 预编译二进制（ABI 与 Electron 版本无关），无需重编；若以后新增需要重编译的原生依赖，把模块名加进 `forge.config.ts` 的数组
